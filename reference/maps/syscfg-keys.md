# syscfg key map

84 syscfg keys are referenced by the device tree (97 entries in all, counting 5 `macaddr/` aliases, 3 `syscfg-mismatch/` fallbacks and 5 `zeroes/` length fillers, which are not keys). A value like `syscfg/WMac/6` means "fill this property from syscfg key `WMac`, 6 bytes"; iBoot does the fill at boot. The keys themselves are written at the factory (see [chapter 13](../../docs/13-lifecycle.md)). **[DT]**
